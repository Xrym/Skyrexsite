## 1. Общая информация
**Skyrex Computers** — веб-приложение для подбора и расчета оптимальных сборок ПК с помощью искусственного интеллекта. Сайт доступен по адресу: [https://skyrex.pro/](https://skyrex.pro/).

Серверная часть развернута на Ubuntu Linux (IP: `87.120.84.33`), работает под управлением Nginx (HTTPS/SSL) и Gunicorn multi-worker (`skyrex.service`).

## 2. Файловая структура

| Файл / Каталог | Назначение |
| :--- | :--- |
| `index.html` | Главная страница сайта, разметка UI-компонентов, подключение стилей и скриптов с версионированием. |
| `style.css` | Основные стили: неоновый киберпанк дизайн, анимация сканирования, сетка Hero, модальные окна, адаптивность. |
| `rig_visualizer.js` | Интерактивный визуализатор сборки ПК (`SkyrexRig`), динамическая SVG-схема, тултипы, парсинг ответов ИИ. |
| `chat_bot.js` | Клиентская часть ИИ-чата: SSE стриминг, автокомплит подсказок при наборе, форматирование Markdown. |
| `auth.js` | Клиентская авторизация: формы логина и регистрации, работа с токенами в LocalStorage. |
| `app.js` | Общие вспомогательные функции сайта. |
| `server.py` | Асинхронный сервер (aiohttp): обработка запросов, интеграция с LLM (Gemini + fallback OpenRouter), системный промпт. |
| `catalog.db` | База данных SQLite с комплектующими (наименования, цены, ссылки на магазины). |
| `users.db` | База данных пользователей (хеши паролей, сессии). |
| `run_scraper.py` / `scraper_menu.py` | Модули парсинга актуальных цен с маркетплейсов (Wildberries, ОнлайнТрейд, DNS, Авито). |
| `run_tg_bot.py` / `tg_admin_bot.py` | Telegram бот администратора для удаленного управления и мониторинга. |
| `deploy.py` | Скрипт автоматического деплоя (Git push -> SSH -> server update -> healthcheck). |
| `nginx.skyrex.conf` | Конфигурационный файл Nginx для сервера. |
| `skyrex.service` | Systemd сервис для автозапуска приложения. |
| `GEMINI.md` | Инструкция и контекстный файл для ИИ-ассистентов Antigravity. |

## 3. Стек технологий
* **Frontend**: HTML5, CSS3 (Modern Flexbox & CSS Grid, CSS Variables), Vanilla JavaScript (ES6+).
* **Backend**: Python 3.10+, `aiohttp`, `gunicorn`, `sqlite3`.
* **AI / LLM**: Google Gemini API (`gemini-2.5-flash`), OpenRouter API (резервный канал высокой доступности).
* **Инфраструктура**: Linux Ubuntu, Nginx, Systemd, Git, SSH / Paramiko.

## 5. Инструкция по развертыванию

Для отправки изменений на рабочий сервер запускается команда:
```bash
python deploy.py "Описание изменений"
```

Скрипт автоматически:
1. Фиксирует изменения в Git.
2. Отправляет коммит в репозиторий GitHub.
3. Соединяется по SSH с сервером `87.120.84.33`.
4. Затягивает код (`git pull`) и перезапускает службу `skyrex.service`.
5. Проверяет корректность ответа сайта по HTTPS.
